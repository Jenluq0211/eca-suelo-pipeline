## Pipeline ECA Suelo
# Descripción
Proyecto desarrollado para automatizar la evaluación de resultados de laboratorio ambiental respecto a los Estándares de Calidad Ambiental (ECA) para Suelo mediante Python y PostgreSQL.

# Objetivo
Implementar un pipeline que permita comparar resultados de laboratorio con valores ECA y almacenar los resultados para su análisis posterior.

# Tecnologías utilizadas
- Python
- PostgreSQL
- Git
- GitHub
